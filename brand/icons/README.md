# SideQuests icon family

All icons use a 24 × 24 grid, a 1.75 px optical stroke, round caps, round joins, and a 2 px internal safe area. Use `currentColor`; do not hard-code brand colors inside product icons. Default sizes are 16, 20, and 24 px. Use 32 px only for an empty state or feature callout.

Rules:

- Keep icons outline-only unless a status requires a filled version.
- Never mix these assets with another icon style in the same interface.
- Do not scale the stroke independently from the icon.
- Pair unfamiliar concepts such as XP or Points with text until repeated use establishes meaning.
- Navigation icons use 24 px; badges use 16 px; buttons use 18 or 20 px.
- The `quest.svg` mark may represent a quest but must not replace the official brand icon.

The family includes Explore, Quest, Reward, XP, Points, Partner, Map, Profile, Achievement, Camera, Photo, QR, Settings, Search, Bookmark, Check-in, Directions, Hidden Gem, Event, Restaurant, Coffee, Art, Music, Outdoors, Nightlife, Scan, and Favorite.
