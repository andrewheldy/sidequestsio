SIDEQUESTS READINESS SITE

This folder is the production build. It does not need Node.js on Netlify.

NETLIFY DROP
1. Unzip the package if needed.
2. Drag the sidequests-readiness folder into https://app.netlify.com/drop
3. The site opens at the domain root.

NETLIFY GIT DEPLOY
- Publish directory: output/netlify/sidequests-readiness
- Build command: pnpm run build:readiness

The PDF presentation is included at:
readiness/sidequests-readiness-brief.pdf
